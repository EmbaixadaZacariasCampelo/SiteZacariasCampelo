# Glossário:

---

| Termo                  | Definição                                                                                                          |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Tática / Cálculo**   | Sequência específica de lances forçados visando ganho material ou vantagem posicional imediata                     |
| **Estratégia**         | Planejamento de longo prazo baseado na avaliação da posição (estruturas de peões, peças boas/ruins, etc.)          |
| **Posição**            | Arranjo das peças no tabuleiro em um determinado momento da partida                                                |
| **Linha ou Variante**  | Sequência específica de lances que pode ser jogada ou analisada                                                    |
| **Cravada ou Pregada** | Quando uma peça não pode se mover sem expor uma peça mais valiosa atrás dela ao ataque                             |
| **Ataque Descoberto**  | Quando uma peça se move revelando o ataque de outra peça por trás dela                                             |
| **Desenvolvimento**    | Colocar as peças em casas ativas desde as posições iniciais (geralmente nas primeiras jogadas)                     |
| **Garfo ou Duplo**     | Ataque simultâneo de duas ou mais peças adversárias por uma única peça                                             |
| **Material**           | Valor total das peças que cada jogador possui no tabuleiro. Ex. ele tem uma vantagem material (ele tem mais peças) |
| **Pendurar**           | Deixar uma peça desprotegida, vulnerável à captura                                                                 |
| **Tomar / Capturar**   | Remover uma peça adversária do tabuleiro ocupando sua casa                                                         |
| **Casa**               | cada quadrado individual do tabuleiro                                                                              |
| **Coordenadas**        | Sistema alfanumérico para identificar casas (letras e números do canto do tabuleiro)                               |
| **Atividade**          | Capacidade das peças de controlar casas importantes e influenciar o jogo                                           |
| **Xeque**              | Ameaça ao rei; O rei deve sair, ou ser protegido da ameaça imediatamente                                           |
| **Xeque-mate**         | Xeque do qual não há escape — fim da partida                                                                       |
| **Afogamento**         | Quando não há lances possíveis e o rei não está em Xeque                                                           |
| **Peão passado**       | Peão sem peões adversários em casas anteriores na mesma coluna ou adjacentes                                       |
| **Coluna aberta**      | Coluna sem peões de nenhuma das cores, ideal para torres                                                           |
| **Coluna Semiaberta**  | Coluna com peões de uma só cor                                                                                     |
| **Infiltração**        | Entrada de uma peça em território adversário                                                                       |
| **Zugzwang**           | Situação onde qualquer movimento enfraquece a posição do jogador                                                   |
| **Jogada forçada**     | Lance obrigatório devido a xeques ou ameaças graves                                                                |
| **Dar um tempo**       | fazer um movimento "inútil" para passar a vez ao adversário                                                        |
| **Sacrifício**         | Perder material intencionalmente para ganhar vantagem posicional ou ofensiva                                       |
| **"Peão fraco"**       | Peão difícil de defender ou que pode ser alvo                                                                      |
| **"Peão forte"**       | Peão bem posicionado que controla casas importantes                                                                |
| **"Peças ruins"**      | Peças com mobilidade limitada pela própria estrutura de peões                                                      |
| **"Precisão"**         | Jogar os lances exatos necessários em uma sequência crítica                                                        |
