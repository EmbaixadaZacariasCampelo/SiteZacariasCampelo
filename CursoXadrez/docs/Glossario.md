# Glossário

---

| Termo                  | Definição                                                                                                          |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Tática / Cálculo**{ #tatica }   | Sequência específica de lances forçados visando ganho material ou vantagem posicional imediata                     |
| **Estratégia**{ #estrategia }         | Planejamento de longo prazo baseado na avaliação da posição (estruturas de peões, peças boas/ruins, etc.)          |
| **Posição**{ #posicao }            | Arranjo das peças no tabuleiro em um determinado momento da partida                                                |
| **Linha ou Variante**{ #linha }  | Sequência específica de lances que pode ser jogada ou analisada                                                    |
| **Cravada ou Pregada**{ #cravada } | Quando uma peça não pode se mover sem expor uma peça mais valiosa atrás dela ao ataque                             |
| **Ataque Descoberto**{ #ataque-descoberto }  | Quando uma peça se move revelando o ataque de outra peça por trás dela                                             |
| **Desenvolvimento**{ #desenvolvimento }    | Colocar as peças em casas ativas desde as posições iniciais (geralmente nas primeiras jogadas)                     |
| **Garfo ou Duplo**{ #garfo }     | Ataque simultâneo de duas ou mais peças adversárias por uma única peça                                             |
| **Material**{ #material }           | Valor total das peças que cada jogador possui no tabuleiro. Ex. ele tem uma vantagem material (ele tem mais peças) |
| **Pendurar**{ #pendurar }           | Deixar uma peça desprotegida, vulnerável à captura                                                                 |
| **Tomar / Capturar**{ #tomar }   | Remover uma peça adversária do tabuleiro ocupando sua casa                                                         |
| **Casa**{ #casa }               | cada quadrado individual do tabuleiro                                                                              |
| **Coordenadas**{ #coordenadas }        | Sistema alfanumérico para identificar casas (letras e números do canto do tabuleiro)                               |
| **Atividade**{ #atividade }          | Capacidade das peças de controlar casas importantes e influenciar o jogo                                           |
| **Xeque**{ #xeque }              | Ameaça ao rei; O rei deve sair, ou ser protegido da ameaça imediatamente                                           |
| **Xeque-mate**{ #xeque-mate }         | Xeque do qual não há escape — fim da partida                                                                       |
| **Afogamento**{ #afogamento }         | Quando não há lances possíveis e o rei não está em Xeque                                                           |
| **Peão passado**{ #peao-passado }       | Peão sem peões adversários em casas anteriores na mesma coluna ou adjacentes                                       |
| **Coluna aberta**{ #coluna-aberta }      | Coluna sem peões de nenhuma das cores, ideal para torres                                                           |
| **Coluna Semiaberta**{ #coluna-semiaberta }  | Coluna com peões de uma só cor                                                                                     |
| **Infiltração**{ #infiltracao }        | Entrada de uma peça em território adversário                                                                       |
| **Zugzwang**{ #zugzwang }           | Situação onde qualquer movimento enfraquece a posição do jogador                                                   |
| **Jogada forçada**{ #jogada-forcada }     | Lance obrigatório devido a xeques ou ameaças graves                                                                |
| **Dar um tempo**{ #dar-um-tempo }       | fazer um movimento "inútil" para passar a vez ao adversário                                                        |
| **Sacrifício**{ #sacrificio }         | Perder material intencionalmente para ganhar vantagem posicional ou ofensiva                                       |
| **"Peão fraco"**{ #peao-fraco }       | Peão difícil de defender ou que pode ser alvo                                                                      |
| **"Peão forte"**{ #peao-forte }       | Peão bem posicionado que controla casas importantes                                                                |
| **"Peças ruins"**{ #pecas-ruins }      | Peças com mobilidade limitada pela própria estrutura de peões                                                      |
| **"Precisão"**{ #precisao }         | Jogar os lances exatos necessários em uma sequência crítica                                                        |
| **"Trocar peças"**{ #trocar-pecas }     | Capturar uma peça adversária e permitir que o adversário capture uma peça de valor equivalente     |
